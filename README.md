# Tuan Ngoc - Developer Portfolio

Personal portfolio for **Chu Tuan Ngoc**, built with the HugoBlox Academic CV template and adapted into a focused software engineering portfolio.

## Featured Projects

- [EnglishParty](https://english-party.web.app/) - CEFR A1-C2 learning platform built with React, TypeScript, Firebase, and PWA tooling.
- [ComiVerse](https://comi-verse.vercel.app/) - cross-platform digital comic and translation ecosystem built with React, Flutter, Spring Boot, PostgreSQL, and Redis.

## Local Development

Requirements: Node.js 22+, pnpm, Go 1.19+, and Hugo Extended 0.165.0.

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

## Deployment

Pushes to `main` are built and deployed through GitHub Actions to GitHub Pages.
